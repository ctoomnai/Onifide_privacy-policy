Onifide

개인정보 처리방침

최종 업데이트: 2026년 9월 6일

이 번역본은 참고용으로 제공됩니다. 내용이 다를 경우 프랑스어 원문이 우선합니다.

이 방침은 Onifide가 어떤 데이터를 수집하는지, 왜 수집하는지, 어디에 저장하는지, 그리고 여러분에게 어떤 권리가 있는지 설명해요. 이해하기 어려운 법률 용어 대신 읽기 쉽게 쓰려고 노력했어요 — 여전히 불분명한 부분이 있다면 저희에게 연락해 주세요(§9 참고).

1. 여러분의 데이터를 책임지는 사람

Onifide는 프랑스 툴루즈에 소재한 개인사업자 Mohamed Djamil(SIREN 108339714, 주 사업장 SIRET 108339714 00017)이 운영해요. 이분이 GDPR상 여러분 데이터의 처리 책임자예요 — 운영자의 첫 번째 제품인 TallUp과 같은 구조예요.

2. Onifide가 아닌 것

데이터 이야기에 앞서: Onifide는 종교적 권위 기관도, 의료 또는 심리 서비스도 아니에요. 꿈 해석은 문서 코퍼스를 바탕으로 AI가 생성한 성찰 도구일 뿐, 절대적인 진리나 진단, 예언이 결코 아니에요. 자세한 내용은 이용약관을 참고해 주세요.

저희는 정확한 위치 정보, 연락처, 사진, 또는 위에 나열된 것 이외의 기기 데이터를 절대 수집하지 않아요. 아침 알림은 여러분의 휴대폰에 예약된 로컬 알림이에요: 이를 실행하기 위해 어떤 기기 식별자나 콘텐츠도 기기 밖으로 나가지 않아요.

4. 여러분의 데이터가 저장되는 곳

여러분의 데이터는 유럽연합 내(AWS eu-central-1 리전, 독일 프랑크푸르트)에 있는 Neon이 호스팅하는 PostgreSQL 데이터베이스에 저장돼요. 모든 것을 기기에만 보관하는 앱과 달리, Onifide는 해석을 생성하고 여러 기기 간에 일기를 동기화하기 위해 서버가 필요해요 — 이는 의도적으로 선택한 아키텍처이지, 빠뜨린 것이 아니에요.

유일한 예외: 생성된 꿈 이미지(Premium/Ultime)는 유럽연합 관할 구역에 생성된 공간의 Cloudflare R2(파일 스토리지)에 저장돼요. 이미지는 기술 식별자로만 식별되며, 여러분의 이메일이나 꿈 텍스트로는 절대 식별되지 않아요.

5. 여러분의 데이터가 거치는 제3자

저희는 꼭 필요한 것만 사용하며, 꿈 내용을 바탕으로 여러분에게 광고를 타겟팅하는 데는 절대 사용하지 않아요(§6 참고).

  • OpenAI(미국): 여러분의 꿈 텍스트는 저희 문서 라이브러리에서 관련 내용을 찾아내는 유사도 벡터(임베딩)를 생성하기 위해, 그다음 해석 자체를 작성하기 위해 OpenAI로 전송돼요. 꿈 텍스트는 진화하는 심리 프로필에 사용되는 라벨(인물, 모티프, 상징)을 추출하기 위해 한 번만 추가로 전송돼요; 그 이후의 집계는 추가 전송 없이 저희 쪽에서 이루어져요. 반면 꿈 이미지 생성에는 원문 텍스트가 절대 전달되지 않아요: 이미 추출된 상징을 짧은 시각적 설명으로 변환한 것만 사용해요. OpenAI는 데이터 처리 계약에 따라 저희를 대신해 이 데이터를 처리해요. OpenAI API를 통해 전송된 데이터는 모델 학습에 사용되지 않으며(일반 소비자용 ChatGPT와 달리, 이것이 API의 기본 동작이에요), 남용 탐지 목적으로 OpenAI에 최대 30일간 보관된 후 삭제돼요.
  • Sentry(오류 추적): 앱의 기술적 오류는 버그를 수정할 수 있도록 Sentry로 보고돼요. 자유 텍스트 필드(꿈 내용, 기분 메모, 연습 대화 기록)는 전송 전에 명시적으로 필터링(스크러빙)돼요 — Sentry 이벤트에 절대 나타나서는 안 돼요.
  • Cloudflare(R2 스토리지): 생성된 꿈 이미지만 호스팅해요(§4 참고). Cloudflare는 여러분의 꿈 텍스트나 일기의 다른 어떤 데이터도 받지 않아요 — 이미지 파일 자체만 받아요. 이 이미지는 계정 삭제와 동시에 R2에서 삭제돼요.
  • 시스템 음성 인식(Apple / Google): 꿈을 타이핑하는 대신 음성으로 입력하면, 앱은 여러분 기기의 오프라인 음성 인식을 우선적으로 사용해요 — 이 경우 오디오는 여러분의 휴대폰을 절대 벗어나지 않아요. 기기가 오프라인으로 텍스트 변환을 할 수 없는 경우(기기 모델, 운영 체제 버전 또는 언어에 따라), 시스템의 음성 인식 서비스(Apple 또는 Google)가 텍스트 변환을 수행하며, 변환하는 동안 오디오가 해당 서비스로 전송돼요. 저희 쪽에서는 변환된 텍스트만 받을 뿐, 오디오는 절대 받지 않아요. 키보드로 꿈을 입력하면 이런 서비스는 전혀 사용되지 않아요.
  • Apple / Google: 이 옵션을 선택한 경우 「Apple/Google로 로그인」 인증을 위해, 그리고 스토어를 통한 구독 관리를 위해 사용돼요.
  • RevenueCat: 스토어와 저희 서버 간의 구독 상태를 관리해요. 구독자 식별자와 스토어에서 전달한 구매 정보를 받으며, 일기 내용은 절대 받지 않아요.
  • Brevo(이메일 발송, 유럽연합): 여러분이 직접 요청한 서비스 이메일만 전달해요 — 이메일 주소 인증 코드와 비밀번호 재설정 코드예요. Brevo는 여러분의 이메일 주소와 해당 메시지의 내용을 받으며, 일기 내용은 절대 받지 않아요. 저희는 뉴스레터나 마케팅 이메일을 전혀 보내지 않아요.

저희는 여러분의 데이터를 누구에게도, 절대 판매하지 않아요.

6. 광고 및 꿈 내용 기반 타겟팅 금지

Onifide에는 어떤 광고 SDK도 포함되어 있지 않아요. 무료 티어는 체험판(첫 번째 꿈 하나 무료 제공)이지, 광고로 운영되는 티어가 아니에요 — 따라서 무엇이든 받아 가는 광고 네트워크는 없어요.

언젠가 광고가 도입되더라도 다음 약속은 그대로 유지돼요: 어떤 광고 네트워크도 여러분의 꿈 내용, 기분 메모, 연습 대화 기록, 또는 이 데이터로부터 계산된 어떤 신호도 받지 않을 거예요. 여러분이 일기에 털어놓은 내용을 기반으로 한 「스마트 타겟팅」은 결코 없을 거예요.

7. 데이터 보관 기간

여러분의 데이터는 계정이 존재하는 동안 보관돼요. 계정을 삭제하면(설정에서 바로 가능해요), 여러분의 데이터(꿈, 해석, 꿈 이미지, 기분, 연습, 심리 프로필, 그리고 계정 자체)는 저희 활성 데이터베이스와 이미지 스토리지에서 즉시 그리고 영구적으로 삭제돼요 — 비활성화가 아니라 실제 삭제예요. 데이터베이스 호스팅 업체가 보관하는 기술적 복원 기록은 이후 최대 7일 이내에 자동으로 만료돼요. 오류 이벤트(Sentry)는 보안 및 디버깅 용도로만 최대 90일간 보관돼요.

8. 여러분의 권리

GDPR에 따라(그리고 유럽연합뿐 아니라 어디에 계시든 모든 이용자에게), 여러분은 언제든지 다음을 할 수 있어요:

  • 데이터 내보내기: 설정 → 「내 데이터 내보내기」에서 전체 데이터(꿈, 해석, 기분, 연습, 심리 프로필)를 JSON 형식으로 내보낼 수 있어요.
  • 계정 삭제: 설정 → 「내 계정 삭제」 — 최종적이며 되돌릴 수 없는 작업이에요.
  • 데이터 처리에 대한 열람, 정정 또는 반대: 저희에게 연락해 주세요(§9).
  • 여러분의 권리가 존중되지 않는다고 판단되면 CNIL(프랑스 개인정보 보호 감독기관, Commission Nationale de l'Informatique et des Libertés, www.cnil.fr)에 진정을 제기할 수 있어요.

10. 최소 연령

Onifide는 만 15세부터 이용할 수 있어요 — 프랑스의 디지털 성년 연령으로, 이 나이 미만은 GDPR상 데이터 처리에 부모의 공동 동의가 필요해요. 꿈의 내용은 비자발적이기 때문에 이용자가 선택하지 않은 어려운 주제가 떠오를 수 있어요; 앱은 이를 절제된 방식으로 다루며 결코 전면에 내세우지 않아요. 저희는 만 15세 미만 아동의 데이터를 고의로 수집하지 않아요.

11. 심리적 고통을 느낄 때

Onifide는 응급 서비스도, 상담 전화도 아니에요. 꿈이나 연습이 실제 고통을 불러일으킨다면, 의료 전문가나 여러분 나라의 상담 서비스에 이야기해 주세요 — 그리고 즉각적인 위험이 있다면 구조 기관에 연락하세요.

12. 이 방침의 변경

저희는 이 방침을 업데이트할 수 있어요. 중요한 변경 사항은 시행 전에 앱 내에서 알려 드릴게요.
