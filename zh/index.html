Onifide

隐私政策

最后更新：2026年9月6日

本译文仅供参考。如有出入，以法语版本为准。

本政策说明 Onifide 收集哪些数据、为何收集、数据存储在哪里，以及你享有哪些权利。我们尽量以易读的方式来写，而不是使用晦涩难懂的法律术语——如果某段内容仍不清楚，请联系我们（见第9条）。

1. 谁对你的数据负责

Onifide 由 Mohamed Djamil 发布，其为个体企业（SIREN 108339714，主营业场所 SIRET 108339714 00017），位于法国图卢兹。他是《通用数据保护条例》（GDPR）意义上你的数据的处理责任人——与发布者的第一款产品 TallUp 采用同一主体结构。

2. Onifide 不是什么

在谈数据之前先说明：Onifide 既不是宗教权威，也不是医疗或心理服务。梦境解读是由人工智能基于文献语料库生成的反思工具，绝不是绝对真理、诊断或预言。详情请参阅使用条款。

3. 我们收集的数据

类别示例目的

梦境内容 你的梦境文本、日期、醒来时的心情、你添加的标签 服务的核心：生成你的梦境解读

除上述内容外，我们绝不收集精确位置数据、联系人、照片或你设备上的其他数据。早晨提醒是一条在你手机上本地安排的通知：触发它时，没有任何设备标识符或任何内容会离开你的设备。

4. 你的数据存储在哪里

你的数据存储在由 Neon 托管的 PostgreSQL 数据库中，位于欧盟境内（AWS eu-central-1 区域，德国法兰克福）。与将所有内容仅保存在你设备上的应用不同，Onifide 需要一台服务器来生成解读并在你的多台设备之间同步日记——这是一个经过慎重考虑的架构选择，而非疏忽。

唯一的例外：生成的梦境图片（Premium/Ultime）存储在 Cloudflare R2（文件存储）上，位于一个以欧盟为司法管辖区创建的存储空间中。图片在那里仅以技术标识符标识，绝不会以你的电子邮箱或梦境文本标识。

5. 你的数据会经由哪些第三方

我们只使用绝对必要的第三方服务，并且绝不会根据你的梦境内容对你进行广告定向（见第6条）。

  • OpenAI（美国）：你的梦境文本会被发送至 OpenAI，用于生成相似度向量（embeddings），以便在我们的文献库中找到相关内容，随后用于撰写解读本身。一个梦的文本还会被发送一次，用于提取为演进式心理画像提供数据的标签（人物、母题、符号）；之后的汇总在我们这里完成，不会再次发送。相反，梦境图片的生成绝不会接收原始文本：它仅基于已提取的符号，这些符号会被转化为一段简短的视觉描述。OpenAI 依据数据处理协议代表我们处理这些数据。通过 OpenAI API 发送的数据不会用于训练其模型（这是 API 的默认运作方式，与面向大众的 ChatGPT 不同），并由 OpenAI 最多保留 30 天用于滥用检测，之后删除。
  • Sentry（错误追踪）：应用的技术错误会上报至 Sentry，以便我们修复缺陷。自由文本字段（梦境内容、心情笔记、练习对话记录）在任何发送之前都会被明确过滤（scrubbing）——它们绝不应出现在任何 Sentry 事件中。
  • Cloudflare（R2 存储）：仅托管生成的梦境图片（见第4条）。Cloudflare 绝不会收到你的梦境文本或你日记中的任何其他数据——只有图片文件本身。这些图片会在你删除账户的同时从 R2 中删除。
  • 系统语音识别（Apple / Google）：如果你选择口述梦境而不是打字输入，应用会优先使用你设备上的离线语音识别——在这种情况下，音频绝不会离开你的手机。当你的设备无法离线转写时（取决于机型、操作系统版本或语言），转写将由系统的语音识别服务（Apple 或 Google）完成，音频会在转写期间传输给该服务。而我们这边只会收到转写后的文本，绝不会收到音频。用键盘输入梦境则不涉及上述任何服务。
  • Apple / Google：如果你选择“通过 Apple/Google 登录”这一选项，用于身份验证；以及通过应用商店管理订阅。
  • RevenueCat：在应用商店与我们的服务器之间管理你的订阅状态。它会收到一个订阅者标识符以及由应用商店传递的购买信息，绝不会收到你日记的内容。
  • Brevo（电子邮件发送，欧盟）：仅传递由你自己触发的服务邮件——你的邮箱地址验证码和密码重置码。Brevo 会收到你的电子邮箱地址和该邮件的内容，绝不会收到你日记的内容。我们不发送任何新闻通讯或营销邮件。

我们绝不会将你的数据出售给任何人。

6. 广告以及不基于你的梦境内容进行定向

Onifide 不内置任何广告 SDK。免费层级是一次试用（赠送第一个梦），而不是靠广告支撑的层级——因此没有任何广告平台会收到任何东西。

如果将来有一天引入广告，以下承诺仍将完整保留：任何广告平台都不会收到你的梦境内容、心情笔记、练习对话记录，或任何基于这些数据计算出的信号。绝不会有基于你在日记中所倾诉内容的“智能定向”。

7. 我们保留你的数据多长时间

只要你的账户存在，你的数据就会被保留。如果你删除账户（可直接在“设置”中操作），你的数据（梦境、解读、梦境图片、心情、练习、心理画像以及账户本身）会从我们的活动数据库和图片存储中立即且永久删除——这不是停用，而是真正的删除。我们的数据库托管商保留的技术恢复历史随后会自动过期，最长不超过 7 天。错误事件（Sentry）最多保留 90 天，仅用于安全和调试目的。

8. 你的权利

根据 GDPR（并适用于我们所有用户，无论身在何处，不仅限于欧盟境内），你可以随时：

  • 导出你的数据：“设置”→“导出我的数据”会生成一份 JSON 格式的完整导出（梦境、解读、心情、练习、心理画像）。
  • 删除你的账户：“设置”→“删除我的账户”——此操作是最终且不可撤销的。
  • 访问、更正你的数据或反对对其进行的处理：请联系我们（第9条）。
  • 提出投诉：如果你认为你的权利未得到尊重，可向 CNIL（法国数据保护机构，Commission Nationale de l'Informatique et des Libertés，www.cnil.fr）投诉。

10. 最低年龄

Onifide 可供 15 岁及以上用户使用——这是法国的数字成年年龄，低于此年龄时，GDPR 要求数据处理须获得父母的共同同意。由于梦境内容并非出于自愿，它有时可能带出用户并未选择的困难主题；应用会以克制的方式处理这些内容，绝不会突出显示。我们不会有意收集属于 15 岁以下儿童的数据。

11. 如遇心理困扰

Onifide 既不是紧急服务，也不是心理援助热线。如果某个梦或某项练习引发了真实的困扰，请与医疗专业人士或你所在国家的援助热线交谈——如遇紧急危险，请联系急救服务。

12. 本政策的变更

我们可能会更新本政策。任何实质性变更都会在生效前在应用内通知你。
